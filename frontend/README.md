# ZILAL TRAVEL — frontend платформы

Публичный сайт и админка/CRM на Next.js App Router, TypeScript и Tailwind CSS. Интерфейс на русском. Бэкенд, база данных, реальная авторизация, оплата и отправка уведомлений в этот этап не входят.

## Запуск в Windows (PowerShell)

Установите Node.js 24 LTS. В PowerShell перейдите в корень распакованного проекта:

```powershell
cd frontend
npm ci
npm run dev
```

Откройте `http://localhost:3000`, админку — `http://localhost:3000/admin`. Остановка: `Ctrl+C`. Если PowerShell блокирует `npm.ps1`, используйте `npm.cmd ci` и `npm.cmd run dev`.

```powershell
npm run build
npm run typecheck
npm test
```

Для Vercel: импортируйте GitHub-репозиторий и задайте Root Directory `frontend`. После обновления ветки `main` Vercel автоматически собирает новую версию, если интеграция подключена. На опубликованном сайте добавьте `/admin` к адресу для открытия админки.

## Публичный сайт

- `/` — все 11 разделов главной.
- `/destinations`, `/destinations/[slug]` — направления и их маршруты.
- `/tours`, `/tours/[slug]` — каталог с поиском, фильтрами по типу, направлению, сложности и длительности; сортировка по цене и длительности. Карточки показывают нагрузку, размер группы и кому подходит поездка. Страница тура: программа с краткими заголовками дней, темп, подготовка, начало маршрута, условия цены, проживание, транспорт, FAQ, галерея и похожие туры. Цена и запрос доступны в начале страницы; есть переходы к разделам.

- `/experiences`, `/experiences/[slug]` — впечатления и связанные маршруты.
- `/about` — подход компании.
- `/journal`, `/journal/[slug]` — журнал и материалы.
- `/gallery` — иллюстрации с подписями.
- `/contacts` — контакты из настроек.
- `/plan` — пошаговое планирование поездки: даты, группа, интересы, проживание, бюджет и контактные данные. `/plan?tour=issyk-kul` выбирает маршрут заранее.

В редакторе тура добавлены необязательные поля «Кому подходит маршрут», «Темп и нагрузка», «Подготовка и важные особенности», «Начало и завершение маршрута» и «От чего зависит итоговая цена». Старые локальные копии продолжают работать: незаполненные сведения показываются как требующие уточнения. Новые тексты исходных примеров не заменяют сохранённые записи автоматически. Чтобы увидеть обновлённые примеры, можно открыть сайт в новом профиле браузера или сначала экспортировать свою копию и затем выбрать «Вернуть примеры».

Форма создаёт только локальный пример лида и назначает первого активного демонстрационного менеджера, если он есть. Команда ZILAL не получает заявку, бронирование не создаётся и деньги не списываются. Публикация черновика в админке влияет на видимость в локальном публичном интерфейсе.

## Админка

- `/admin` — обзор и сводные показатели.
- `/admin/leads` — список и воронка со всеми статусами из архитектуры.
- `/admin/customers`, `/admin/bookings`, `/admin/partners`, `/admin/payments`, `/admin/employees` — карточки, поиск, создание, редактирование и удаление записей.
- `/admin/tours`, `/admin/destinations`, `/admin/experiences`, `/admin/journal`, `/admin/gallery`, `/admin/reviews` — редакторы контента, статусы публикации и выбор иллюстрации.
- `/admin/reports` — показатели из локальных данных. Суммы USD, KGS и EUR считаются отдельно, без смешивания валют.
- `/admin/activity` — история локальных изменений.
- `/admin/settings` — тексты Hero, контакты, экспорт/импорт JSON и возврат к исходным примерам.

У каждой коллекции есть адрес `/admin/<раздел>/new` для создания и `/admin/<раздел>/<id>` для редактирования. Связи выбираются по именам: клиент, тур, менеджер, партнёр и бронирование. Карточка показывает связанные записи. Удаление записи, на которую ссылаются другие, блокируется: сначала снимите связи или используйте архивный статус.

**Админка открыта без пароля и предназначена для демонстрации frontend.** Роли сотрудников можно выбрать, но они пока не ограничивают доступ. Не используйте здесь настоящие персональные данные или платёжные реквизиты.

## Где сохраняются изменения

Исходные примеры находятся в `data/platform.ts`, остальные файлы `data/*.ts` используются для начального наполнения. `PlatformProvider` хранит изменения под ключом `zilal-platform-v1` в `localStorage`. Сохранённая копия восстанавливается после перезагрузки; вкладки одного браузера синхронизируются. Сообщение об успехе появляется только после записи. Конфликт редактирования одной записи блокирует сохранение и оставляет правки в форме. При ошибке хранилища поля также сохраняются в открытой форме. Повреждённая локальная копия не перезаписывается автоматически; экспорт позволяет сохранить её для восстановления.

Новые материалы создаются черновиками. Редакторы предупреждают о несохранённых изменениях при переходе по ссылке или закрытии вкладки. Сортировка туров по цене работает внутри одной выбранной валюты.

Изменения **не записываются в исходные файлы, GitHub или общую базу**, не видны другому человеку или на другом устройстве. Локальный сайт и Vercel имеют разные копии данных. Для переноса используйте «Экспорт JSON» и «Импорт JSON» в настройках; импорт проверяет формат и связи. Очистка браузерного хранилища удаляет локальные изменения. «Вернуть примеры» также заменяет их — экспортируйте копию заранее.

Данные нового опубликованного тура доступны по его slug сразу в том же браузере, включая прямой переход и перезагрузку. Неизвестный локальный slug показывает состояние «Материал не найден»; сервер не знает содержимое браузерного хранилища, поэтому эта страница не является серверным HTTP 404. Обычные неизвестные маршруты обрабатываются страницей 404.

## Структура и оформление

```text
frontend/
  app/(public)/        # Публичные маршруты и общий каркас
  app/admin/           # Маршруты рабочего пространства
  components/public/  # Каталоги, детали, планирование поездки
  components/admin/   # Обзор, таблицы, редакторы, настройки
  components/providers/ # Общий локальный слой данных
  components/home/    # Главная
  components/layout/  # Шапка и подвал
  components/ui/      # Общие визуальные элементы
  data/content/       # Словари главной и тексты платформы
  data/admin/config.ts # Поля, связи и статусы редакторов
  data/platform.ts    # Начальные примеры всех коллекций
  hooks/              # Предупреждение о несохранённых изменениях
  tests/              # Регрессионные тесты без дополнительных библиотек
  lib/storage.ts      # Проверяемая запись и координация вкладок
  lib/platform.ts     # Форматирование и проверка импорта
  types/              # TypeScript-модели
  public/images/      # Пейзажные SVG-плейсхолдеры
```

Палитра: молочный `#FFFDF8`, тёмно-синий текст `#173849`, бирюзовый `#007F89`, разделители `#DCE7E7`. Публичные заголовки — Cormorant Garamond; текст и рабочая админка — Manrope. Шрифты с кириллицей подключены локально через Fontsource. Дополнительных библиотек интерфейса, графиков и анимации нет.

Изображения отображаются через `next/image`. Пока используются подписанные локальные SVG-иллюстрации. Загрузка фотографий и общее медиахранилище оставлены на следующий этап. Старый статический сайт и `images/hero.jpg` в checkout отсутствовали; их можно добавить позднее без удаления или замены оригиналов.

`data/content/ru.ts` и `en.ts` имеют одинаковую структуру для главной. Новые интерфейсные тексты вынесены в `data/content/platform.ts`, подписи редакторов — в `data/admin/config.ts`. Подготовлена структура словарей; полный перевод новых страниц, коллекций и переключатель языка ещё не реализованы.

Метаданные страниц сформированы для начальных примеров; изменения только в localStorage не меняют серверные SEO-метаданные. Индексация прототипа отключена. Публикационный SEO, общая сохранность данных, права доступа и реальные бронирования потребуют следующего этапа с бэкендом.

Архитектура проекта: `../docs/architecture/architecture.md`.
